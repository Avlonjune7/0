# 项目工作约定

> 写作提示：用已发现的实际路径替换下面说明，复用现有约定，省略不适用项。不要将此提示或空占位复制到项目。

## 文档与任务位置

| 信息 | 权威位置 | 何时读取或更新 |
| --- | --- | --- |
| 项目运行与导航 | 根 README 或已有入口 | 启动项目、运行方式改变时 |
| 功能规格 | 实际规格位置；不存在时写约定路径 | 改变业务行为前读取，批准变更后同步 |
| 任务记录 | 实际 tracker 或本地任务位置 | 复杂任务规划、进度变化或交接时 |
| UI 规范 | 实际 DESIGN.md；无 UI 则省略 | UI 改动前读取，规范变更按授权处理 |
| 模块说明 | 实际模块文档位置 | 修改对应模块前读取，契约改变后同步 |

## 任务约定

记录本项目实际任务管理方式、命名与状态规则。未采用外部 tracker 时，复杂任务默认在 docs/tasks 下每任务一文件，状态为计划中、进行中、受阻、已完成。小改不为记录流程新建任务文档。

## 维护边界

规格描述已认可的功能要求，模块说明描述当前实现。两者不一致时记录依据并处理差异，不自动将实现视为正确需求。按本次改动同步受影响文档，保留已有有效内容；验证记录区分未运行、实际通过和实际失败。
