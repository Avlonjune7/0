# 个人界面约定

以用户本次要求和项目已确认的设计为准。已有项目按根 `DESIGN.md` 的适用范围执行。新项目或明确重新选型时，React 默认 Astryx，Vue 默认 shadcn-vue。其他技术栈沿用项目或用户已确认的选择。

- 缺少 `DESIGN.md`、选型、迁移、组件复用有疑问或进行界面设计时，读[组件与设计系统](references/components.md)的相关部分。
- 布局、响应式或交互验收、浏览器排查、前端性能或网页审查时，读[页面验证](references/verification.md)的相关部分。

局部调整使用受影响组件和项目设计约定即可。涉及已确认设计或组件体系的变更，按现有授权范围执行。
