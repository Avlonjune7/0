# 个人 UI 约定

以用户本次要求和项目根 `DESIGN.md` 为准。新项目或明确重新选型时，**React 默认 Astryx，Vue 默认 shadcn-vue**；其他技术栈沿用项目或用户既有选择。

- 组件选型/迁移、公共控件复用、建立或调整 `DESIGN.md`、界面设计 → 读 [组件与设计系统](references/components.md)
- 布局/交互验收、浏览器排查、前端性能或 UI 评审 → 读 [页面验证](references/verification.md)
